# GASO — شنو وصلنا ليه؟

هاد المشروع نسخة تجريبية فقط فوق بيئة Ethereum محلية، ماشي عملة حقيقية منشورة للبيع.

- `contracts/GASO.sol`: مليون GASO وبلا سك إضافي.
- `contracts/GASOPaymaster.sol`: نموذج Paymaster يستعمل GASO كتعويض لرسوم ETH.
- `test/gaso.test.js`: اختبارات أولية لإنشاء العملة وصلاحيات Paymaster.

## شنو باقي؟

1. نتأكدو أن اختبارات GitHub Actions نجحت.
2. نحضرو محفظة ذكية متوافقة مع ERC-4337 وBundler.
3. نمولو Paymaster بعملة ETH **تجريبية** على Base Sepolia.
4. نرسلو UserOperation ونتأكدو من المعاملة فمستكشف الشبكة.

**الاختبارات الأولية ما كتعنيش أن دفع الغاز بعملة GASO خدام دابا.**

ممنوع نستعملو مفاتيح أو أموال حقيقية فهاد التجربة. مشروع تجريبي غير مدقق أمنياً، والسعر الحالي ديال GASO/ETH كيحدده صاحب Paymaster يدوياً وما عندو حتى علاقة بسعر السوق.
